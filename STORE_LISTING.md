# Store Listing: WebNovel Ultimate Chapter Copier

## Short description (under 132 characters)

Copy full web novel chapters to your clipboard with one click, a shortcut, or auto-copy for the next chapter.

## Full description

WebNovel Ultimate Chapter Copier copies the full text of a chapter from supported novel sites to your clipboard. Use the popup button, a keyboard shortcut, or turn on Auto-Copy to copy each next chapter when you open it. Options include copy format, title inclusion, a preview, and an optional Ctrl + A that selects only the chapter.

Built in for WebNovel. You can add other novel sites under Settings, Custom sites. The browser asks permission for each site you add, and you can remove it at any time.

Chapter text is processed on your device. Nothing is sent to any server.

Disclaimer: This extension is independent and is not affiliated with or endorsed by any website it works on. It copies text a page already displays, for your personal reading. You are responsible for following each site's terms and applicable copyright law.

## Permission notes for the reviewer

- **storage:** saves your settings locally.
- **offscreen and clipboardWrite:** write copied chapter text to the clipboard.
- **scripting:** runs the extension on custom sites you add.
- **optional host access (all sites):** the extension requests access to a specific site only when you add it in Custom sites. It never requests access on its own.
